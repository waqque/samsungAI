# 3.1 Бинарная классификация? Бинарная кросс-энтропия!

## Задача регрессии (повторение)

**Цель:** Аппроксимировать (упростить) размеченную выборку кривой через нейронную сеть.

**Архитектура сети:**
```
x → [Скрытый слой: сигмоиды] → y (линейный выход)
```

**Ключевые элементы:**
- Скрытый слой: Сигмоидные нейроны
- Выходной слой: Линейная активация
- Loss-функция: Средний квадрат ошибки (MSE)

**Процесс обучения:** Подбор весов нейронов для минимизации MSE.

Если решать задачу регрессии с помощью нейронной сети с большим количеством линейных слоев, можно использовать ту же функцию потерь. Выбор функции потерь не зависит от характеристик модели — он определяется природой задачи.

## Задача бинарной классификации

**Пример:** Различение котов и псов на картинке (или других данных: аудио, видео, числовые признаки).  
**Условие:** Каждая входная выборка принадлежит одному из двух классов (взаимно исключающие).  
**Фокус:** Выход нейронной сети (независимо от архитектуры входного слоя).

**Архитектура для бинарной классификации:**
```
x (картинка/аудио/признаки) → [Скрытый слой: сигмоиды] → z (линейный) → σ(z) (сигмоида) = P(кот)
```

**Ключевые элементы:**
- Положительный класс: Кот = +1 (вероятность P)
- Отрицательный класс: Пёс = 0 (1-P)
- Выход: Сигмоида преобразует линейный выход z в вероятность
- Интерпретация: σ(z) = вероятность принадлежности к положительному классу

На выходе сети мы видим сигмоиду. Без неё можно обойтись, но тогда сеть будет дольше обучаться: придётся ориентироваться в пространстве решений бесконечного размера, а не в интервале от 0 до 1 включительно.

**MSE + сигмоида = плохая комбинация** для бинарной классификации.

## Бинарная кросс-энтропия для сигмоиды

**Альтернатива MSE:** Бинарная кросс-энтропия (BCE).

**Формула BCE (для одного примера):**
```
L = -t * log(p) - (1-t) * log(1-p)
```

**где:**
- p — вероятность положительного класса (выход сигмоиды)
- t — истинная метка (0 или 1)

**Почему BCE работает хорошо:**

1. Всегда безопасно:
   - p всегда между 0 и 1 (не включая границы)
   - log(p) и log(1-p) всегда определены
   - Нет деления на 0 и логарифмов отрицательных чисел

2. Ключевые свойства:
   - Подходит для конечных значений входа
   - Хорошо сочетается с сигмоидой
   - Градиенты не зависают (в отличие от MSE)

**BCE решает проблему паралича сигмоиды.**

**Вывод:** BCE — функция потерь для оценки вероятностей и любых значений в интервале .

# 3.2 Многоклассовая классификация? Софтмакс!

## Задача многоклассовой классификации

**Пример:** Кот, пёс, велосипед, автомобиль (4 класса).  
**Условие:** Каждая картинка содержит ровно один класс из множества.

**Архитектура сети:**
```
x → [Скрытые слои] → [4 выхода: y1, y2, y3, y4] → SoftMax → [P1, P2, P3, P4]
```

- 4 отдельных выхода — по одному на класс
- Вероятности суммируются к 1: sum(Pi) = 1

## SoftMax — функция активации

**Что делает:**
1. Берет все линейные выходы сети (y)
2. К каждому применяет экспоненту
3. Нормализует: Pi = exp(yi) / sum(exp(yj))

Без суммы экспонент в знаменателе результат может быть больше 1, а вероятности должны быть в .

**Результат:** Вероятности для каждого класса, которые всегда суммируются к 1.

**Отличие от бинарной:** Вместо одной сигмоиды — SoftMax для множества классов.

## Свойства и производная SoftMax

**Основные свойства SoftMax:**
- Всегда > 0: экспоненты всегда положительны
- Всегда < 1: числитель < знаменателя
- Сумма = 1: sum(Pi) = 1

**Итог:** Идеальные вероятности для многоклассовой классификации.

Мы считаем производную функции потерь по выходу из нейросети, чтобы понять, как изменить выходы для уменьшения лосса.

## Кросс-энтропия для SoftMax

**Loss-функция для многоклассовой классификации:** Кросс-энтропия:
```
L = -sum(tc * log(pc))
```

**где:**
- pc = SoftMax-вероятность класса c
- t = таргет (1 — истинный класс, 0 — остальные)

**Пример:** Если истинный класс — кот (индекс 1):
```
L = -log(P_кот)
```

## Связь с бинарной классификацией

**Вырождение при 2 классах:**
- SoftMax(2) → Сигмоида
- Cross-Entropy(2) → BCE

**Вывод:** Cross-Entropy + SoftMax = стандарт для многоклассовой классификации.

## SoftMax в многоклассовой классификации

```
x → [Скрытые слои] → [y1, y2, y3, y4] → Softmax → [P1, P2, P3, P4] → Cross-Entropy Loss
```

- yi: Линейные выходы (-∞ до +∞) по одному на класс
- Pi: Вероятности (сумма = 1)
- Loss: Кросс-энтропия — оптимизируется без проблем

**Особенность Softmax:** "Функция активации" в кавычках.

**Отличие от обычных активаций (сигмоида, ReLU):**
- Обычные: Работают с одним значением независимо
- Softmax: Работает с **всем вектором выходов сразу**

**Почему?**
```
P1 = exp(y1) / (exp(y1) + exp(y2) + exp(y3) + exp(y4))
```
Для P1 нужны **все** y1, y2, y3, y4.

**Зависимость между нейронами выходного слоя.**

**Вывод:** Softmax — это **трюк нормализации**, а не классическая активация.

# 3.3 Локализация, детекция, сегментация и super-resolution

## Задача локализации объекта

**Что такое локализация?**  
**Цель:** Найти объект на картинке (например, кота) и определить его **положение + размер**.

**Архитектура сети:**
```
Картинка → [Скрытые слои] → 5 выходов:
1. P(кот) — вероятность наличия кота [0, 1]
2. x_center — координата центра X
3. y_center — координата центра Y
4. width — ширина кота
5. height — высота кота
```

**Ограничения задачи (для упрощения):**
1. Только 1 кот или 0 — исключение неоднозначности "какой кот?"
2. Кот есть → центр его должен быть в пределах картинки. Если центр снаружи — кота нет (даже если видно ухо)
3. Видим центр + нос → кот есть

Ограничения упрощают loss-функцию и активации.

**Проблема с сигмоидой в локализации:**  
Функция очень насыщена ближе к 0 и к 1.

Если сеть предсказала (p, xc, yc, w, h), p>0, а кота на самом деле нет:
1. Loss будет таким же, как для (p=0, xc, yc, w, h)
2. Штрафуем сеть только за классификацию (p), игнорируя координаты

## Сегментация объекта (пиксельная классификация)

**Цель:** Для каждого пикселя картинки сказать — кот это или фон.

**Архитектура:**
```
Картинка (H×W×3) → [Сеть] → Картинка скорров (H×W×1) → Сигмоида → Вероятности (H×W×1)
```

На вход — RGB картинка, на выход — та же размерность, но **1 канал** = вероятность "кот" для каждого пикселя.

| Компонент | Что                  | Почему?                          |
|-----------|----------------------|----------------------------------|
| Активация | Сигмоида на каждый пиксель | 0=фон, 1=кот                |
| Loss      | BCE для каждого пикселя   | Сигмоида + бинарная классификация |

**Loss:**
```
Loss = sum(BCE(пиксель_1) + BCE(пиксель_2) + ... + BCE(пиксель_n))
```

**Результат:** Маска кота с вероятностями для каждого пикселя.

## Автоэнкодер (сжатие размерности)

**Задача обучения без учителя:** Сжать картинку в маленькое число (embedding), потом восстановить.

**Архитектура:**
```
Картинка (28×28=784) → Энкодер → Embedding(32) → Декодер → Картинка (784)
```
**Bottleneck:** 784 → 32 → 784

**Loss-функции:**

| Вариант | Активация   | Loss                        |
|---------|-------------|-----------------------------|
| MSE     | Линейная    | Средний квадрат ошибки по пикселям |
| BCE     | Сигмоида    | Бинарная кросс-энтропия по пикселям |

**Loss = MSE(вход, восстановленная)** или **BCE(вход, восстановленная)**.

**Итог:** Сжимаем → теряем детали → учимся восстанавливать.

Сжатое изображение может быть **одномерным вектором**.

## Super Resolution (увеличение разрешения)

**Цель:** Низкое разрешение ×2 по x, y.  
**Пример:** 64×64 → 128×128.  
**1 пиксель входа → 4 пикселя выхода.**

**Как обучать?**
1. Берем картинки высокого разрешения
2. Уменьшаем их в 2 раза (downsample)
3. **Вход:** Низкое разрешение. **Цель:** Высокое разрешение (оригинал)

**Loss = MSE(pred_128×128, оригинальная_128×128)**

**Пример процесса:**
```
Оригинал 128×128 ↓(×1/2) Картинка 64×64 → Сеть → Предсказание 128×128
                                            ↓
                                        Сравнить с оригиналом
```

Сеть учится **додумывать недостающие пиксели**.

## Универсальный алгоритм для любой задачи

**Задача → [Выходы сети] → [Правильная активация] + [Правильный Loss] → Решение**

**Алгоритм:**
1. Определи выходы (что сеть должна предсказывать?)
2. Подбери активацию (диапазон значений)
3. Выбери loss (BCE, MSE, CE, MAE)

**Примеры связок:**
- Сигмоида → BCE (вероятности 0-1)
- Softmax → Cross-Entropy (вероятности сумма=1)
- Экспонента → MSE(log) (0 до ∞, относительная ошибка)
- Линейная → MSE (действительные числа)

**⚠️ Softmax — дорогая функция**, стараемся избегать.

**Любую задачу можно решить**, подобрав правильную активацию + loss.

# 3.5 Строим первую нейронную сеть

## Разделение данных

| Тип данных | Назначение | Почему важен? |
|------------|------------|---------------|
| train      | Обучение   | Подбор весов  |
| validation | Контроль качества | Проверка переобучения, подбор гиперпараметров |
| test       | Финальная оценка | Реальное качество модели |

**Проблема:** Если обучаться на полном датасете и на нём же валидироваться → не заметим переобучения (сеть запомнила выборку).

**Эпоха** — итерация обучения на **всём датасете**.

## Bias (смещение)

**Bias** — параметр нейронной сети, добавляемый к взвешенной сумме входных данных перед активацией.

**Формула нейрона:**
```
z = sum(wi * xi) + b
```
где b — bias.

**Зачем нужен bias:**
- Учитывает постоянные компоненты сигнала
- Делает модель гибкой и независимой от сдвигов данных
- Корректирует точку пересечения границы решений
- Позволяет нейрону активироваться при нулевых входах

**Без bias:** Модель менее универсальна, не работает со сдвинутыми данными.

## Практические рекомендации

- Перемешивать данные перед каждой эпохой
- Батчи экономят оперативную и видео-память
