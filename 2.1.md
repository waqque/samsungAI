

## Модуль 2. Блок 1. Нейрон и нейронная сеть

### 1.1. Математическая модель нейрона

Нейрон — компонент, из которого состоит нервная система человека.

**Сопоставление биологического и математического нейрона:**

- Тело нейрона (накопление заряда) — сумматор.
- Дендриты (входящие сигналы) — входы: x0, x1, x2.
- Аксон (исходящий сигнал) — выход: y.
- Синапсы (сила связи) — веса: w0, w1, w2.
- Порог активации — функция активации: f.

**Формула нейрона:**  
y = f(w0*x0 + w1*x1 + w2*x2 + b)

#### Этапы работы нейрона

1. **Взвешенная сумма (сумматор):**  
   z = w0*x0 + w1*x1 + w2*x2 + b  
   (получаем линейную функцию)

2. **Функция активации:**  
   y = f(z)

**Пояснение параметров:**
- Веса (w) определяют важность каждого входа (x).
- Смещение (b) — сдвиг функции, аналог порога.
- Функция активации (f) преобразует сумму (z) в выходное значение; обеспечивает нелинейность.

#### Функции активации

- **Step (пороговая):** 1, если сумма (z) >= 0, иначе 0 (аналогично биологическому нейрону).
- **Sigmoid (сигмоида):** 1 / (1 + e^(-z))
- **ReLU:** max(0, z)
- **Tanh (гиперболический тангенс):** функция активации, вносящая нелинейность; диапазон от -1 до 1.

#### Обучение нейрона

- Цель: подобрать веса (w) и смещение (b) для минимизации ошибки.
- Используется градиентный спуск — обновление параметров по градиентам ошибки.

**Итог:**  
Нейрон = линейная модель + функция активации.  
Веса (w) и смещение (b) — параметры для обучения.  
Много нейронов вместе образуют нейросетевой слой.

#### Количество параметров

У математической модели нейрона настраиваемых параметров на 1 больше, чем входов.

#### Разделяющая поверхность

- Место, где функция активации меняет значение с 0 на 1, называется разделяющей поверхностью.
- Разделяющая поверхность задается уравнением, когда аргумент функции активации равен 0.
- Это уравнение задает прямую. С одной стороны от прямой функция равна 1, с другой — 0.
- Разделяющая поверхность — плоскость, заданная вектором w и смещением b.
- С той стороны от разделяющей поверхности, куда указывает вектор w, функция активации равна 1.

**Особенности нейрона с пороговой функцией активации:**
- Разделяющая поверхность линейна.
- При двух входах — разделяющая поверхность — прямая.
- Разделяющая поверхность — подмножество пространств векторов w.
- Разделяющая поверхность — геометрическое место точек, где функция активации меняет значение.

#### Сигмоида

- Результат вычисления функции сигмоиды принимает только положительные значения.
- Параметр температуры позволяет регулировать наклон сигмоиды.

### 1.3. Булевы операции в виде нейронов

#### Оператор "не"

- Унарная булева функция (принимает один аргумент).
- В виде нейрона: один вход и один выход.

#### Логическая операция "и"

- Бинарная булева функция (принимает два аргумента x1 и x2).
- Булева — каждый аргумент может быть только 0 или 1.
- Всего комбинаций входных параметров — 4.
- В виде нейрона: два входа, один выход.

***

### 1.4. От нейрона к нейронной сети

#### Нейрон линеен, сеть нелинейна

- Соединяя нейроны в сеть, можно получать нелинейные разделяющие поверхности.

**Нейронные сети с линейной разделяющей поверхностью:**
- Нейронная сеть без функции активации.
- Один нейрон.

**Замечание:**  
Соединять полносвязные нейроны с линейной функцией активации в многослойную нейронную сеть не имеет смысла, если каждый нейрон получает на вход все аргументы, как и остальные нейроны в этом же слое.
