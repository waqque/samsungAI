# Конспект по машинному обучению

## 2.1 Градиентный спуск

**Градиентный спуск** — алгоритм оптимизации, используемый при обучении нейронных сетей для **минимизации функции потерь** — разницы между прогнозируемыми выходами сети и фактическими целевыми значениями.

**Скорость обучения \( \eta \)** определяет размер шагов обновления для достижения минимума.

*Если неверно установить \( \eta \)*: 
1. **Колебание** вокруг точки одного и того же значения
2. **Подъём** вместо спуска  
3. Невозможность дойти до минимума

**Для достижения минимума** надо двигаться в направлении **вектора антиградиента**.

**Антиградиент** — вектор, противоположный направлению градиента. Указывает **направление наискорейшего убывания** функции.

*Для функции с несколькими локальными минимумами*:
1. Может найти **локальный минимум** вместо глобального
2. **Пробовать разные начальные точки**

## 2.2 Линейная регрессия

**Линейная регрессия** — простой алгоритм ML для моделирования зависимости между **независимыми переменными** (факторами) и **зависимой переменной**.

**Предположение**: зависимость как **прямая линия** (или гиперплоскость).

**Задачи регрессии**:
1. Определение **зарплаты по навыкам**
2. **Балл ЕГЭ по школьным оценкам**

*Не считается ML-методом*, т.к. коэффициенты рассчитываются **однозначно** методами **линейной алгебры**.

**Проблемные признаки**:
1. *Сильно коррелированные*
2. *Имеющие выбросы*

**Метрики**:
- **MAE** (средняя абсолютная ошибка): модуль разности
- **MSE** (среднеквадратичная): квадрат разности

## 2.4 Логистическая регрессия

**Логистическая регрессия** — для **бинарной классификации**. Оценивает **вероятность принадлежности к классу**.

**Классификация** — разделение на категории (**обучение с учителем**). Пример: группа крови по параметрам.

**Метрики качества**:
| Метрика   | Формула                                                                                                                       | Описание                             |
| --------- | ----------------------------------------------------------------------------------------------------------------------------- | ------------------------------------ |
| Accuracy  | tp+tn/tp+tn+fp+fn                                                                    | Доля правильных предсказаний         |
| Precision | tp/tp+fp                                                                                               | Точность положительного класса       |
| Recall    | tp/tp+fn                                                                                               | Полнота (выявление всех релевантных) |
| F1-score  | 2*(recall*precision)(/recall+precision) | Гармоническое среднее                |

## 2.6 Метрики качества. kNN. kMeans

**KNN** (k-ближайших соседей) — основан на **гипотезе компактности**: близкие объекты имеют **схожие значения**.

**Решает задачу классификации**.

**Кластеризация** (**без учителя**) — группировка данных так, чтобы объекты в кластере **похожи друг на друга** больше, чем на другие.

**Задачи кластеризации**:
1. **Группировка биологических клеток**

**Silhouette score** — метрика качества кластеризации: схожесть внутри кластера vs с другими кластерами.

## 2.8 Деревья решений

**Дерево решений** — иерархическая структура из **узлов** и **ветвей**. Каждый узел — проверка условия.

**Структура**:
1. **Корневой узел** — весь датасет
2. **Внутренние узлы** — разбиение по признаку
3. **Листовые узлы** — результат классификации/регрессии

**Индекс Джини** (0-1) — определяет **наиболее однородные подмножества**. *Максимум при чистом классе*.

**Главное преимущество**: **интерпретируемость**.

**Цель**: обобщить зависимости между признаками.

**Избежание переобучения**:
1. Ограничить **число элементов в листе**
2. Ограничить **глубину дерева**

**Выбор разбиения**: полный перебор или **статистический анализ**.

## 2.9 Случайный лес и градиентный бустинг

**Ансамбль деревьев** — объединяет **несколько деревьев** (*голосование/среднее*) для повышения точности.

**Решает**: классификацию и регрессию.

**Random Forest** («случайный лес»):
- Строит **много деревьев** на **разных подвыборках**
- **Случайность**: подвыборки данных + признаки

**Градиентный бустинг**:
- Деревья **небольшой глубины**
- Использует **бутстрэп**

**Бутстрэп** — метод повторной выборки **с возвращением** для оценки неопределённости.

**В Random Forest случайность**: выбор подвыборки данных и признаков.
