## Модуль 2. Блок 2. Строим первую нейронную сеть

### 2.1. Восстановление зависимости нейронной сети

Размеченная обучающая выборка — это набор объектов, для которых известны:

1. **Признаки** (\(x_1, \dots, x_n\)): характеристики объекта (например, для дня — номер дня в году, облачность, температура, давление).
2. **Метки** (\(y_1, \dots, y_n\)): целевая переменная (например, скорость ветра в м/с).

**Пример**: По признакам дня предсказать силу ветра. Этот набор данных используется для обучения нейронной сети.

#### Разделение выборки

Перед обучением выборку разделяют на три части (хорошая практика):

- **Тренировочный датасет (train)**: используется напрямую для обучения модели.
- **Валидационный датасет (val)**: для подстройки гиперпараметров обучения (не участвует в самом обучении, но помогает улучшить результаты). Обычно модель видит его раньше тестового.
- **Тестовый датасет (test)**: для финальной проверки модели (не используется и не подгоняется ранее).

Хороший результат на тестовом датасете подтверждает, что модель обобщила информацию и **не переобучилась**.

#### Скрытая зависимость и модель данных

Рассматривается задача восстановления скрытой зависимости \(f(x)\), где:
- \(x\) — признаки дня (например, давление),
- \(y\) — скорость ветра (целевая переменная).

#### Модель с шумом

Реальные данные содержат погрешность измерений:

\[
y_i = f(x_i) + e_i
\]

- \(f(x_i)\) — истинная (скрытая) зависимость скорости ветра от параметров.
- \(x_i\) — координаты замера (параметры дня при измерении).
- \(y_i\) — наблюдаемое значение (измеренная скорость ветра).
- \(e_i\) — шум (погрешность): может быть систематической или случайной.

**Цель**: восстановить \(f(x)\) по зашумленным данным \(\{(x_i, y_i)\}\).

**Отклонение наблюдаемых значений от идеальной зависимости** возникает по причинам:

1. Человеческий фактор: человек неправильно провел измерения.
2. Недостаточный набор параметров.
3. Измерительный прибор был плохо откалиброван.
4. Наблюдаемая величина случайным образом отклоняется от средних значений.

### 2.2. Компоненты нейронной сети

#### Построение нейронной сети

Для восстановления зависимости \(f(x)\) используют нейронную сеть как **"черный ящик" с ручками** (веса нейронов и смещения).

**Основные компоненты**:

1. **Архитектура**:
   - Состав (слои, нейроны).
   - Связи между элементами.
   - Функции активации.

2. **Функция потерь**:
   - Определяет "наилучшее" положение ручек.
   - Минимум функции потерь = оптимальная модель.

3. **Метод оптимизации**:
   - Алгоритм изменения весов: "на сколько и как крутить ручки".
   - Использует градиенты (направление улучшения) для уменьшения потерь.

**Дополнительно: Метрики**
- Не влияют на обучение напрямую.
- Показывают качество решения (например, точность — % угаданных предсказаний).
- Полезны для настройки процесса обучения.

**Важно**: Метрики ≠ функция потерь.

**Аналогия**: Нейронная сеть — пульт с ручками. Функция потерь подсказывает, в каком направлении их крутить, чтобы прийти к правильному решению.

#### Первая нейронная сеть

**Задача**: Восстановление скрытой зависимости \(f(x)\) с одним входом (\(x_i\)) и одним выходом (\(y_i \approx f(x_i)\)).

**Архитектура сети**:

```
x → [Скрытый слой: много сигмоидных нейронов] → y (линейный выход)
```

- **Вход**: \(x_i\) (аргумент функции).
- **Скрытый слой**: Много нейронов с сигмоидной активацией \(\sigma(z) = \frac{1}{1 + e^{-z}}\).
- **Выходной нейрон**: Линейный (\(f(x) = x\), только сумматор, без нелинейной активации).

**Цель обучения**: Подобрать параметры (веса и смещения) скрытого слоя и выходного нейрона, чтобы выход сети \(y\) наилучшим образом соответствовал наблюдаемым данным \(y_i\).

#### Настраиваемые параметры нейронной сети

В сети `[Скрытый слой сигмоид] → y(линейный)` настраиваются:

1. **Параметры скрытого слоя (первый слой)**:
   - **Веса** (\(w_1, w_2, \dots\)): регулируют крутизну сигмоиды.
     - Большой вес → сигмоида быстро переходит от 0 к 1.
     - Маленький вес → медленный рост.
   - **Смещения** (\(b_1, b_2, \dots\)): сдвигают сигмоиду влево/вправо.
     - Большое положительное \(b\) → сдвиг влево.
     - Большое отрицательное \(b\) → сдвиг вправо.

2. **Параметры выходного слоя (второй слой)**:
   - **Веса** (\(w'_1, w'_2, \dots\)): задают амплитуду сигмоиды (функция растет от 0 до \(w'\)).
   - **Смещение** (\(b'\)): дополнительный сдвиг выходной линейной комбинации.

**Итого**: Веса и смещения обоих слоев подбираются для аппроксимации \(f(x)\).

#### Аппроксимация зависимости суммой сигмоид

**Иллюстрация ручного подбора параметров** (не обучение, а демонстрация принципа).

**Цель**: Приблизить целевую функцию \(y(x)\) суммой сигмоид из сети.

**Пошаговый подбор нейронов**:

1. **Первый нейрон** (приближает левые точки):
   - Центр: \(b_{1_1}\) → смещение = \(-b_{1_1}\).
   - Амплитуда: \(w'_{2_1}\) (диапазон сигмоиды).
   - Смещение выхода: \(b'_{2_1}\) (здесь = 0).
   - Крутизна: \(w_{1_1}\) (подгонка под точки).

2. **Последующие нейроны** (улучшают аппроксимацию):
   - Каждый новый нейрон подгоняет остаточные точки.
   - Повторяют процедуру для своих параметров.
   - Общее смещение \(b'_{2n}\) уже зафиксировано (новые сигмоиды от 0).
   - Амплитуда: \(w'_{2n}\).

**Результат**: Выход сети = сумма сигмоид с разными параметрами.
- С каждым нейроном аппроксимация точнее.
- Сумма перестает напоминать одиночную сигмоиду → **универсальная аппроксимация**.

#### Теорема универсальной аппроксимации

Нейронные сети с одним скрытым слоем (полносвязные, сигмоидная активация) могут аппроксимировать:

1. Любую **ограниченную функцию**.
2. С не более чем **счётным числом разрывов**.

**Вывод**: Такой класс покрывает очень широкий спектр функций с произвольной точностью.

#### Функция потерь: MSE

**Роль**: Измеряет, насколько хорошо модель решает задачу.
- Плохие параметры → большая потеря.
- Хорошие параметры → маленькая потеря.

**Свойства**:
- Минимизация MSE → точная аппроксимация \(f(x)\).
- Популярна для задач **регрессии** (восстановление зависимостей).

**Утверждение** (ложное): "Чем больше значение функции потерь, тем лучше нейронная сеть решает задачу".

### 2.3. Алгоритм настройки нейронной сети

#### Обучение нейронной сети: Градиентный спуск

**Параметры модели**: Вектор \(w_0\) (все веса и смещения сети).

**Алгоритм градиентного спуска**:

1. Вычислить градиент функции \(L(w)\) в текущей точке (направление наибольшего роста \(L\)).
2. Сделать шаг в противоположном направлении:

\[
w_{k+1} = w_k - \alpha \cdot \nabla L(w_k)
\]

где \(\alpha\) — **скорость обучения** (фиксированная, например, 0.1).

3. Повторять до сходимости.

**Особенности**:
1. Находит **локальный минимум** (не обязательно глобальный).
2. Может застрять в неоптимальном минимуме.
3. **Плюс**: простой и эффективный метод оптимизации.

**Утверждения**:
1. Направление градиента — **обратно** направлению наискорейшего убывания функции.
2. Градиент — вектор из **производных** функции по всем переменным.
3. Шаг градиентного спуска — **одновременно** для всех параметров модели.

#### Требования к функции потерь для градиентного спуска

Функция потерь \(L\) должна удовлетворять двум условиям:

1. **Дифференцируемость**:
   - \(L\) должна быть дифференцируемой по всем параметрам сети в большом множестве точек.
   - Допускаются редкие недифференцируемые точки (меры 0).

2. **Ненулевая производная**:
   - Градиент ≠ 0 практически везде (кроме идеального решения).
   - **Плохо**: "Точность" (accuracy) — производная часто = 0 → неинформативна.

**Пример: MSE**

Производная MSE по предсказанию:

\[
\frac{\partial \hat{y}_i}{\partial \text{MSE}} = -\frac{2}{N} (y_i - \hat{y}_i)
\]

- Ненулевая.
- Идеально для задач регрессии.

**Вывод**: Дифференцируемость + информативный градиент → обучение возможно.

#### Градиентный спуск: Обратное распространение ошибки

**Проблема**: Зная градиент по выходу, нужно вычислить производные по всем параметрам сети.

**Правило цепочки** (производная сложной функции).

**Представление сети как графа**:

```
x → f₁ → f₂ → f₃ → f₄ → y₄ → L (функция потерь)
         ↓
       f₄(y₂, y₃)
```

- Узлы — операции (\(f_i\)), промежуточные значения.
- Рёбра — зависимости между вычислениями.
- Вход — \(x\) (признаки).
- Выход — \(L\) (потери).

**Цель**: Пошагово распространить градиент от выхода к входу по графу для всех параметров.

Зная математическую модель сети, мы спускаемся по пространству параметров к минимуму функции потерь.

**Ключевые термины**:
- **Точность** — метрика.
- **Сигмоида** — функция активации.
- **Средний квадрат ошибки (MSE)** — функция потерь.

Задание графа вычисления аналогично выбору архитектуры сети.

### 2.6. Семинар: Реализация градиентного спуска

#### Градиентный спуск: поиск локального минимума

**Алгоритм**:

1. **Начальная точка**: \(x_t\) (случайная).
2. **Вычислить градиент**: \(f'(x_t)\) — направление наискорейшего роста.
3. **Шаг в минимум** (против градиента):

\[
x_{t+1} = x_t - \alpha \cdot f'(x_t)
\]

где \(\alpha\) — **learning rate** (шаг): обычно \(10^{-3}\), \(10^{-4}\). Можно изменять в процессе.

4. Повторять до сходимости.

**Итерации**: \(x_0 \to x_1 \to x_2 \to \dots \to\) локальный минимум.

**Особенности**:
- Находит **локальный минимум** (не гарантирует глобальный).
- \(\alpha\) критически важен:
  - Слишком большой → расхождение.
  - Слишком маленький → медленная сходимость.

**Вывод**: Метод градиентного спуска нужен для нахождения локального минимума функции и используется для настройки весов нейронной сети.

**Техническая деталь**: `requires_grad=True` — тензор переменная, по которой можно считать производные.
