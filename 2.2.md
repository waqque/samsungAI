

## Модуль 2. Блок 2. Строим первую нейронную сеть

### 2.1. Восстановление зависимости нейронной сети

Размеченная обучающая выборка — это набор объектов, для которых известны:

- Признаки (например, для дня — номер дня в году, облачность, температура, давление).
- Метки (целевая переменная, например, скорость ветра в м/с).

Пример: по признакам дня предсказать силу ветра. Набор данных используется для обучения нейронной сети.

#### Разделение выборки

Перед обучением выборку разделяют на три части:

- Тренировочный датасет (train): используется для обучения модели.
- Валидационный датасет (val): для подстройки гиперпараметров.
- Тестовый датасет (test): для финальной проверки модели.

Хороший результат на тестовом датасете показывает, что модель обобщила информацию и не переобучилась.

#### Скрытая зависимость и модель данных

Рассматривается задача восстановления скрытой зависимости f(x), где:
- x — признаки дня (например, давление).
- y — скорость ветра (целевая переменная).

#### Модель с шумом

Реальные данные содержат погрешность измерений:
y_i = f(x_i) + e_i

- f(x_i) — истинная зависимость скорости ветра от параметров.
- x_i — координаты замера.
- y_i — наблюдаемое значение (измеренная скорость ветра).
- e_i — шум (погрешность): может быть систематической или случайной.

Цель: восстановить f(x) по зашумленным данным.

Отклонение наблюдаемых значений от идеальной зависимости может быть вызвано:
- Человеческим фактором.
- Недостаточным набором параметров.
- Плохой калибровкой прибора.
- Случайными отклонениями.

### 2.2. Компоненты нейронной сети

#### Построение нейронной сети

Для восстановления зависимости f(x) используют нейронную сеть как "черный ящик" с ручками (веса и смещения).

Основные компоненты:
- Архитектура: слои, нейроны, функции активации.
- Функция потерь: определяет "наилучшее" положение ручек.
- Метод оптимизации: алгоритм изменения весов.

Дополнительно: метрики (например, точность) показывают качество решения, но не влияют на обучение напрямую.

#### Первая нейронная сеть

Задача: восстановление зависимости f(x) с одним входом и одним выходом.

Архитектура сети:
- Вход: x (аргумент функции).
- Скрытый слой: много нейронов с сигмоидной активацией.
- Выходной нейрон: линейный (только сумматор, без нелинейной активации).

Цель обучения: подобрать параметры (веса и смещения) скрытого слоя и выходного нейрона, чтобы выход сети наилучшим образом соответствовал наблюдаемым данным.

#### Настраиваемые параметры нейронной сети

В сети настраиваются:
- Параметры скрытого слоя (веса и смещения): регулируют крутизну и сдвиг сигмоиды.
- Параметры выходного слоя (веса и смещения): задают амплитуду и сдвиг выходной линейной комбинации.

#### Аппроксимация зависимости суммой сигмоид

Выход сети — сумма сигмоид с разными параметрами. С каждым нейроном аппроксимация становится точнее.

#### Теорема универсальной аппроксимации

Нейронные сети с одним скрытым слоем (полносвязные, сигмоидная активация) могут аппроксимировать любую ограниченную функцию с произвольной точностью.

#### Функция потерь: MSE

Функция потерь (MSE) измеряет, насколько хорошо модель решает задачу. Минимизация MSE приводит к точной аппроксимации f(x). MSE популярна для задач регрессии.

### 2.3. Алгоритм настройки нейронной сети

#### Обучение нейронной сети: Градиентный спуск

Параметры модели — все веса и смещения сети.

Алгоритм градиентного спуска:
- Вычислить градиент функции потерь.
- Сделать шаг в противоположном направлении.
- Повторять до сходимости.

Особенности:
- Находит локальный минимум.
- Может застрять в неоптимальном минимуме.
- Простой и эффективный метод.

#### Требования к функции потерь для градиентного спуска

Функция потерь должна быть дифференцируемой и иметь ненулевую производную почти везде.

#### Градиентный спуск: Обратное распространение ошибки

Для вычисления градиентов используют правило цепочки. Градиент распространяется от выхода к входу по графу сети для всех параметров.

#### Ключевые термины

- Точность — метрика.
- Сигмоида — функция активации.
- Средний квадрат ошибки — функция потерь.

### 2.6. Семинар: Реализация градиентного спуска

#### Градиентный спуск: поиск локального минимума

Алгоритм:
- Начальная точка: случайная.
- Вычислить градиент.
- Сделать шаг в минимум (против градиента).
- Повторять до сходимости.

Особенности:
- Находит локальный минимум.
- Скорость обучения критически важна.
