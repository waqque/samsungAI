# 1.2

## 1.2.1 Градиентный спуск

1) Вам дана функция, в каком направлении нужно двигаться, чтобы достичь её минимума?  
— В направлении вектора антиградиента.

2) Что может случиться, если неверно установить значение скорости обучения?  
— Колебание точки вокруг одного и того же значения. Градиентный спуск наоборот приведет к подъему. Не позволит дойти до минимума.

3) Для функций, у которых несколько локальных минимумов в дополнение к глобальному.  
— Градиентный спуск может найти локальный минимум вместо глобального, необходимо пробовать запускать обучение из разных начальных точек.


## 1.2.2 Линейная регрессия

1) Выберите задачи, которые можно отнести к задачам регрессии.  
— Определение зарплаты человека по его навыкам, определение балла ЕГЭ ученика по его оценкам в школе.

2) Линейную регрессию не считают методом машинного обучения, потому что  
— Значения коэффициентов линейной регрессии можно рассчитать однозначно с помощью методов линейной алгебры.

3) Какие признаки осложняют расчёт регрессии?  
— Сильно коррелированные между собой, имеющие выбросы.

4) Сопоставьте следующие определения:  
— MAE — рассчитывает ошибку на основании модуля разности.  
— MSE — рассчитывает ошибку на основании квадрата разности.


## 1.2.4 Логистическая регрессия

1) Какие типы задач можно отнести к задачам классификации?  
— Определение группы крови по биологическим параметрам.

2) Сопоставьте следующие определения:  
— Precision — доля верно угаданных объектов заданного класса среди всех попыток классификации этого класса.  
— Accuracy — доля правильных классификаций из всех попыток классификации.

3) Задача классификации — это задача обучения с учителем.

4) F-мера — среднее гармоническое точности и полноты.


## 1.2.6 Метрики качества. kNN. kMeans.

1) Методом K ближайших соседей решается задача  
— Классификации.

2) Что такое кластеризация?  
— Процесс разделения данных на группы схожих объектов.

3) Какие типы задач можно отнести к задачам кластеризации?  
— Определение наиболее близких друг к другу типов биологических клеток.

4) Задача кластеризации — это задача обучения без учителя.

5) Какая метрика оценки качества кластеризации измеряет внутрикластерное сходство?  
— Силуэт.


## 1.2.8 Деревья решений

1) Какое значение критерия Джини будет, если все объекты принадлежат одному классу?  
— Минимальное.

2) Каково основное преимущество модели «Дерево решений» перед заказчиком?  
— Наибольшая интерпретируемость.

3) Какова цель построения дерева решений в задаче классификации?  
— Создать модель, способную обобщить зависимости между признаками.

4) Как избежать переобучения модели «Дерево решений»?  
— Ограничить число элементов в листах, ограничить глубину дерева.

5) Как происходит выбор признака для деления в вершине?  
— На основании полного перебора признаков или анализа статистических свойств выборки.


## 1.2.9 Случайный лес и градиентный бустинг

1) Какие задачи можно решать с помощью ансамблей деревьев?  
— Классификации и регрессии.

2) Как лучше описать метод построения случайного леса?  
— Построение многих деревьев решений на разных подвыборках данных.

3) Какие типы базовых моделей используются в градиентном бустинге?  
— Деревья решений небольшой глубины, бутстрап.

4) Что такое случайность в случайном лесе и как она влияет?  
— Случайный выбор подвыборки данных и признаков; повышает обобщающую способность модели.


# 2.1

## 2.1.1 Математическая модель нейрона

1) Сколько настраиваемых параметров имеет математическая модель нейрона?  
— На один больше, чем входов.

2) Какие значения выдает пороговая функция активации?  
— 0 или 1.

3) Все верные утверждения:  
— Разделяющая поверхность нейрона линейна.  
— Для двух входов — это прямая.  
— Разделяющая поверхность задается формулой ⟨w⃗ ,x⃗ ⟩ + b = 0.  
— Это множество точек, где функция активации меняет значение.

4) Верные утверждения:  
— Сигмоида принимает только положительные значения.  
— Ввод параметра температуры регулирует наклон сигмоиды.


## 2.1.4 От нейрона к нейронной сети
1) Какие нейронные сети имеют только линейную разделяющую поверхность?  
— Нейронная сеть без функции активации; один нейрон.

2) Имеет ли смысл соединять полносвязанные нейроны с линейной функцией активации в многослойную сеть?  
— Нет.


# 2.2

## 2.2.1 Восстановление зависимости нейронной сетью

1) Выберите верные утверждения:  
— Тренировочная выборка используется для обучения сети.  
— Модель видит валидационный датасет раньше тестового.

2) Почему наблюдаемые значения отклоняются от теоретических?  
— Ошибки измерений, недостаток учтённых параметров, плохая калибровка прибора, случайные отклонения.


## 2.2.2 Компоненты нейронной сети

1) Какая функция подсказывает, в каком направлении изменить параметры?  
— Функция потерь.

2) Верно ли, что чем больше значение функции потерь, тем лучше работает сеть?  
— Нет.


## 2.2.3 Алгоритм настройки нейронной сети

1) Верные утверждения:  
— Направление градиента противоположно направлению наискорейшего убывания.  
— Градиент составлен из частных производных по всем параметрам.  
— Шаг градиентного спуска делается для всех параметров одновременно.

2) По чему и куда мы спускаемся?  
— По пространству параметров нейросети — к минимуму функции потерь.

3) Сопоставьте функцию и применение:  
— Точность — метрика.  
— Сигмоида — функция активации.  
— MSE — функция потерь.

4) Задача графа вычислений аналогична  
— Выбору архитектуры нейросети.


## 2.2.6 Реализация градиентного спуска

1) Для чего нужен метод градиентного спуска?  
— Для поиска локального минимума функции; используется для настройки весов нейронной сети.


# 2.3

## 2.3.1 Бинарная классификация — бинарная кросс-энтропия!

1) Можно ли использовать ту же функцию потерь для регрессии с большим числом слоев?  
— Да, выбор функции потерь не зависит от архитектуры модели.

2) Можно ли обойтись без сигмоиды на выходе?  
— Можно, но обучение будет дольше и сложнее.


## 2.3.2 Многоклассовая классификация — Softmax!

1) Зачем в знаменателе сумма экспонент по всем выходам?  
— Чтобы результат не был равен 0 и функция была дифференцируемой.

2) Зачем считать производную функции потерь по выходу из сети?  
— Чтобы определить, как изменить выходы для уменьшения функции потерь.

3) Что такое 1 − pᵢ?  
— Суммарная уверенность во всех остальных классах.


## 2.3.3 Локализация, детекция, сегментация и super-resolution

1) Недостатки использования сигмоиды для локализации?  
— Сильное насыщение при значениях, близких к 0 и 1.

2) Если предсказана вероятность p>0, но объекта нет?  
— Наказываем сеть только за ошибочную классификацию (p), координаты при этом не учитываются.

3) Верные утверждения про автоэнкодер:  
— Сжатое изображение может быть одномерным вектором.


## 2.3.5 Семинар: строим нейронную сеть

1) В примере y = sin(x) + noise. Верные утверждения:  
— Это задача регрессии — предсказание вещественного числа.  
— Метод unsqueeze_ добавляет размерность, чтобы каждый элемент стал вектором.

2) Для чего деление датасета на train, validation, test?  
— Train — обучение, validation — подбор гиперпараметров, test — оценка финального качества без переобучения.

3) Что такое эпоха?  
— Итерация обучения на всём датасете.


## 2.3.6 Семинар: классификация в PyTorch

1) Правильные утверждения:  
— Полезно перед каждой эпохой перемешивать данные.  
— Батчи экономят память.  
— За одну эпоху сеть видит весь обучающий датасет.


# 2.4

## 2.4.1 Самый обычный градиентный спуск

1) Когда вектор изменения параметров сонаправлен линиям уровня?  
— Никогда: при движении вдоль линии уровня функция не меняется.

2) Что произойдет при увеличении learning rate в 100 раз?  
— Поведение модели станет непредсказуемым.

3) Верные утверждения:  
— Градиентный спуск не всегда снижает функцию потерь.  
— Не всегда сходится к глобальному минимуму.  
— Не обязательно, что скорость обучения 1 — оптимальна.

4) Если все объекты батча одинаковы:  
— При усреднении лосса поведение как в SGD; при суммировании — как SGD с увеличенным learning rate в 100 раз.


## 2.4.2 Модификации градиентного спуска

1) Как связаны α (learning rate) и β (momentum)?
— Никак, настраиваются независимо.

2) Может ли произойти деление на 0 в знаменателе?  
— Может, если все градиенты равны 0 — значит, точка оптимума.

3) Верные утверждения:  
— Иногда SGD показывает лучшие результаты, чем RMSProp.  
— Заранее нельзя определить, какой оптимизатор лучше.


## 2.4.4 Семинар: классификация рукописных чисел

1) Всегда ли увеличение точности на train ведет к росту на test?  
— Нет.


# 2.5

## 2.5.1 Свертка, каскад сверток

1) Как считать градиент для max-pooling?  
— Градиент равен 1, проходит только через ячейку с максимумом.

2) Можно ли использовать padding=2 для ядра 3×3?  
— Да, любые паддинги меньше размера ядра корректны.


## 2.5.5 GoogleNet, ResNet (2015)

1) Когда градиент в ResNet будет нулевым?  
— Если градиент на батче равен 0 или достигнут минимум функции потерь.

2) Почему в ResNet отказываются от полносвязных слоев?  
— Глубокие сети и без них хорошо дискриминируют объекты.

3) Почему ResNet неважен размер изображения, а важен масштаб деталей?  
— В конце усреднение тензора масштабирует его под полносвязный слой.

4) Какой трюк появился в какой сети?  
— LeNet — активация tanh, свёртки, pooling.  
— AlexNet — каскад свёрток, ReLU.  
— VGG — добавление слоёв постепенно, свёртки 1×1.  
— GoogleNet — инцепшн-модули с разными размерами свёрток.  
— ResNet — обходные (skip) соединения.

## 2.6.2 Батч-нормализация

1) После нормализации разделяющая поверхность проходит через начало координат. Так будет всегда?  
— Только если она проходит через математическое ожидание всей обучающей выборки.

2) Чем отличается BatchNorm при тренировке и валидации?  
— На тренировке — статистики по текущему батчу.  
— На валидации — усредненные статистики по всей истории обучения.
